# Lalit — Professional Engineering Portfolio

## Included
- Modern white/blue/black responsive portfolio
- Separate HTML, CSS and JavaScript
- Experience, education, skills, projects and certificates
- Interactive 3D model viewer
- Individual project pages
- Repository-friendly asset folders

## Add your files
Profile:
`assets/images/profile/profile.jpg`

Project images:
`assets/images/projects/project-01.jpg`
`project-02.jpg`
etc.

Certificates:
`assets/images/certificates/certificate-01.jpg`
etc.

3D model:
`assets/models/main-model.glb`

## Important
The 3D viewer uses Google's `<model-viewer>` web component from its CDN, so an internet connection is needed for the viewer library when the site is loaded.
